Пример работы всех команд консольного меню:
```text
1 — добавить | 2 — список | 3 — завершить | 4 — удалить | 5 — поиск | 0 — выход

# Добавляем первую задачу с высоким приоритетом
> 1
Название: Купить продукты
Приоритет (1–3): 1
Создана задача #1

# Добавляем вторую задачу с более низким приоритетом
> 1
Название: Сварить суп
Приоритет (1–3): 2
Создана задача #2

# Смотрим общий список задач
> 2
Незавершённые задачи:
#1 Купить продукты [new], приоритет 1
#2 Сварить суп [new], приоритет 2

# Отмечаем первую задачу как выполненную
> 3
ID: 1
Готово

# Ищем задачу #2 по ID
> 5
ID: 2
#2 Сварить суп [new], приоритет 2

# Проверяем список: задачи разделились по статусам
> 2
Незавершённые задачи:
#2 Сварить суп [new], приоритет 2
Завершённые задачи:
#1 Купить продукты [done], приоритет 1

# Завершаем вторую задачу
> 3
ID: 2
Готово

# Удаляем первую задачу
> 4
ID: 1
Готово

# Убеждаемся, что осталась только одна завершённая задача
> 2
Завершённые задачи:
#2 Сварить суп [done], приоритет 2

# Выходим из программы
> 0
Работа приложения завершена
```
