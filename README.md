# Практическая работа № 1. Знакомство с Go

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Debian GNU/Linux 13 (trixie)
- Версия Go: go version go1.27.4 linux/amd64
- Редактор: VS code

## Выполнено

Созданы: карточка участника, программа с информацией о пользователе, конвертера времени, счётчика среднего

Проверено: проект запускается локально. Всё успешно отработало

## Запуск программы
Запуск программы для карточки учaстника
```bash
go run ./cmd/card
```  
Запуск программы для переводчика времени из минут в полные часы + оставшиеся минуты
```bash
go run ./cmd/time-converter
```  
Запуск программы для нахождения среднего числа
```bash
go run ./cmd/time-converter
```  

## Проверка сборки и оформления

```text
go fmt ./...
go build ./...
```
